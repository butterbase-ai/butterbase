Butterbaseで構築した、製品の構成を備えるアプリ集です。[Examples](../Examples)の小規模な機能別デモよりも広い範囲を含み、データベース・認証・関数・React画面をまとめて確認できます。

## butterbaseCRM

創業者向けのOSS CRMです。会社と連絡先、商談、会議、メモ、メールキャンペーン、SNS投稿、ワークスペースのAIエージェントを扱います。Gmailとカレンダーを同期し、通信相手の連絡先・会社情報を取り込みます。

AIエージェントはパイプラインについて質問に答え、操作を提案します。書き込み前に利用者が確認・承認します。SNSの対応状況は接続設定と画面を確認してください。現行UIではInstagramとTikTokを準備中として表示します。

[機能と構成](butterbaseCRM/README.ja.md) · [クイックスタート](butterbaseCRM/QUICKSTART.ja.md)

## butterSupport

サイトに埋め込むサポートウィジェットと、運営者が問い合わせを扱う管理画面です。ヘルプ文書に加え、接続した製品データからアカウント状態・決済失敗・最近のエラーを参照できます。

ヘルプセンターのURLを登録する基本構成と、製品のデータ・操作をsubstrate経由で接続する拡張構成があります。初期の返信モードは承認待ちです。現行画面では自律性モードも設定できるため、顧客へ送信する条件を設定画面で確認してください。

[機能と構成](butterSupport/README.ja.md)

## 利用する

各`backend/`はプラットフォーム上の状態を読むためのミラーです。Gitリポジトリの取得だけでは、実行中のバックエンドは作成されません。自分のバックエンドを持つには、Butterbaseアプリを複製します。

```bash
butterbase clone <source_app_id> my-app
```

複製後は各READMEでフロントエンドを設定してください。`butterbase clone`はマネージド機能で、[Butterbaseアカウント](https://butterbase.ai)が必要です。セルフホスト時は`backend/`のスキーマ・RLS・関数を自分の環境へ導入します。

## 設定と日本語表示

`.env.example`を`.env`へ、フロントエンド側の例を`.env.local`へコピーし、自分のアプリIDやサービスキーを設定します。`bb_sk_*`やOAuthのクライアントシークレットをコミットしないでください。

CRM・サポート管理画面の言語欄で「日本語」を選べます。初期表示は英語で、選択はブラウザーに保存します。切り替えても入力途中の値は保持します。顧客が入力した文面・名前・API値・サーバーから届くエラーは翻訳しません。

ウィジェットの初期言語は`data-lang="ja"`で指定できます。保存済みの言語選択を優先し、埋め込み先ページの`html lang`を変更しません。
