# @butterbase/sdk

[English](README.md) | 日本語

ブラウザー・Node.js・Denoで使えるButterbaseのTypeScript SDKです。

## インストール

```bash
npm install @butterbase/sdk
```

## 使い方

| ガイド | 内容 |
|---|---|
| [はじめる](docs/ja/getting-started.md) | クライアント作成、読み書き、0.xからの移行 |
| [認証](docs/ja/authentication.md) | サインイン、セッション、認証イベント、保存先 |
| [ストレージ・関数・クエリ](docs/ja/data-and-functions.md) | ファイル操作、関数呼び出し、検索条件 |
| [React・Deno・型](docs/ja/react-typescript.md) | Reactでの認証状態、Deno、型推論 |
| [外部連携とほかのクライアント](docs/ja/integrations.md) | 管理者設定、利用者のOAuth、ツール実行、各機能 |
| [エラー処理](docs/ja/errors.md) | 型付きエラー、エラーコード、独自fetch |

コード例の識別子・API値・URLは英語版と共通です。キーやアプリIDは、例の値を自分の環境へ置き換えてください。
