**テンプレート**は、誰でも複製できる公開Butterbaseアプリです。複製すると、スキーマ、セキュリティポリシー、関数、Durable Objects、ソースファイルがそろった新しいアプリを所有できます。選んだリージョンでバックエンドも起動します。

スターターリポジトリだけを渡す仕組みではありません。データベースを接続する追加作業は不要で、複製時にプロビジョニングとマイグレーションが済み、デプロイできます。

現在、公式テンプレートとしてAI対応CRMとAIサポートデスクを公開しています。**[公開テンプレート一覧](/ja/templates/available/)**を参照してください。

<span id="why-start-from-a-template"></span>

## テンプレートから始める理由

**共通の実装を省けます。** 認証、テーブル設計、RLSポリシー、関数の雛形、ストレージバケット、CORSなど、アプリに必要な土台が連携した状態で用意されています。

**実際に動いたアプリから始められます。** テンプレートは計画段階の設計ではなく、デプロイされたアプリと実際にリクエストを処理したスキーマのコピーです。

**複製先を自分で所有できます。** 自分の組織、プラン、リージョンに作成され、複製元への依存、ライセンス確認、外部への定期連絡はありません。公開者が元のアプリを削除しても、複製したアプリは動き続けます。

**互いのシークレットを共有しません。** APIキー、OAuthクライアントシークレット、BYOK認証情報はコピーしません。テンプレートが必要とする環境変数の**名前**は確認できますが、値は引き継ぎません。

**アプリ固有の設定は自動で埋まります。** `BUTTERBASE_API_URL`と`BUTTERBASE_APP_ID`は新しいアプリの値になります。`BUTTERBASE_API_KEY`用のスコープ付きキーも新規発行でき、複製した関数は初回呼び出しから自分のバックエンドへ接続できます。

**複製前に必要な設定を確認できます。** 事前確認APIは関数とDurable Objectsが使う環境変数を列挙し、自動設定されるものと自分で入力するものを示します。

**普段の作業環境から複製できます。** ダッシュボード、CLI、REST API、MCP接続のAIエージェントは、同じ複製処理を利用します。

<span id="what-you-get-in-a-clone"></span>

## 複製されるもの

| コピーするもの | コピーしないもの |
|---|---|
| データベースのスキーマ：テーブル、列、インデックス | エンドユーザーのアカウントとセッション |
| 行レベルセキュリティのポリシー | OAuthの**クライアントシークレット** |
| サーバーレス関数のコード | 関数の環境変数の**値** |
| Durable Objectクラス | BYOKのAIプロバイダーキー |
| リポジトリのファイル（最後にpushしたスナップショット） | [カスタムドメイン](/ja/core-concepts/custom-domains/) |
| 公開済みフロントエンド（接続先を新しいアプリへ変更） | — |
| シークレットを含まない設定：ストレージ、CORS、OAuthプロバイダーとリダイレクトURL、AIモデルの既定値 | 課金とStripe Connectの設定 |
| アプリ共通の環境変数 | 呼び出し履歴と監査ログ |
| 公開者が`_seed: true`を指定したテーブルの行 | 呼び出し履歴と監査ログ |

詳細は[複製先の設定](/ja/templates/configure/)を参照してください。

<span id="how-a-clone-runs"></span>

## 複製処理の流れ

複製は非同期です。すぐに返る`job_id`で進捗をポーリングします。次の段階を順に進むため、ステータスから現在位置を確認できます。

`pending` → `processing` → `replaying_schema` → `replaying_rls` → `replaying_durable_objects` → `replaying_functions` → `replaying_config` → `copying_repo` → `seeding_data` → `completed`

失敗時は`error_message`が返り、再試行できます。成功時も、認証フックを再接続できなかった場合などに`warnings[]`が返ることがあります。内容を確認してください。

<span id="limits"></span>

## 制限

| 項目 | 値 |
|---|---|
| ユーザーごとの複製開始数 | 1時間に5件 |
| ユーザーごとの同時実行数 | 3件 |
| 複製元の条件 | `visibility: public`、かつ`butterbase repo push`を1回以上実行済み |
| クォータ | 複製先は新規アプリとしてプランのプロジェクト数上限に算入 |
| 名前の一意性 | アプリ名は全体で一意。使用済みの名前には`409`を返す |
